# 🎨 Graff-Folio

_Un portfolio léger, éco-conçu et accessible pour mettre en valeur le travail de Thibault Lemaire, un graffeur professionnel basé en Charente Maritime._

---

## ✨ Présentation

**Graff-Folio** est un site vitrine minimaliste pensé pour un artiste graffeur.  
Il met l’accent sur :

- 🖼️ **La mise en avant de ses œuvres** avec un design épuré.
- 🌱 **L’éco-conception** : un site optimisé, léger en ressources et respectueux de l’environnement numérique, respect des bonnes pratiques du Le Référentiel Général d'Éco-conception des Services Numériques (RGESN).
- ♿ **L’accessibilité** : respect des critères du Référentiel général d'amélioration de l'accessibilité (RGAA).

Ce projet est un **front-end pur** (HTML, CSS, JavaScript vanilla), sans dépendances lourdes.

---

## 🚀 Fonctionnalités

- 📸 Galerie d’œuvres affichées en random.
- 📝 Page de présentation de l’artiste.
- 📱 Design responsive pour une expérience fluide sur mobile, tablette et ordinateur.
- ⚡ Chargement rapide grâce à un code optimisé et des images compressées.
